Welcome to Stand Up

Sitting at your desk all day? Is your back starting to complain? Do you need to be reminded to stand up? Then this simply little web site is for you.

This web site does not work on mobile phones. It works great on desktop computers thought. You should go and give it a try.

If you want to receive system notifications to stand up then you will need to turn them on within the browser.
