Welcome to Stand Up Helper

Sitting at your desk all day? Is your back starting to complain? Do you need to be reminded to stand up? Then this simply little tool is for you.

This tool only works on mobile phones if you install it first. You'll get notifications when to stand up and when to sit back down. Press the INSTALL button and then wait a second or two for it to do its thing.

If you want to receive system notifications to stand up then you will need to turn them on within the browser.
